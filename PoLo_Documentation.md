## 1. What is PoLo?

**PoLo** is a multipurpose Discord bot designed to make servers more interactive, easier to manage and more fun.

PoLo combines moderation and utility tools with entertainment commands, AI-powered features and server configuration options.

### Main features

- 🤖 PoLo AI
- 🎮 Fun and social commands
- 🛠️ Server utilities
- 🎫 Ticket and support systems
- 🧠 Akinator
- 📺 YouTube tools
- 🖼️ AI image generation
- ⚙️ Server configuration
- 🔐 Permission-based commands
- ✨ PoLo+ features

# 2. Getting Started

## Adding PoLo to your server

To use PoLo, invite the bot to your Discord server and authorize the permissions required by the features you want to use.

> **Important:** Never grant permissions that are unnecessary for your server's intended use.

After adding PoLo, use the available slash commands to configure the bot.

# 3. Commands

PoLo primarily uses Discord slash commands.

## AI

### `/ai config`

Configure the AI system for your server.

Available configuration options include:

- Enable or disable PoLo AI.
- Select the channel where the AI should respond.
- Configure AI-related server settings.
- Additional role/personality controls may be available with **PoLo+**.

Example:

```text
/ai config
```

The configuration menu allows server administrators to control how PoLo AI operates in their server.

---

## Fun

PoLo includes interactive commands designed for friends and communities.

Examples include:

```text
/hug
/cuddle
/slap
```

These commands are intended for harmless entertainment and social interaction.

Additional fun commands may be added over time.

---

## Akinator

### `/aki`

Start an Akinator-style guessing game.

PoLo will ask questions and use your answers to attempt to determine the character you are thinking of.

Example:

```text
/aki
```

Follow the buttons and questions displayed by PoLo to play.

---

## YouTube

### `/yt`

Search for information about YouTube channels.

PoLo supports channel searches using information such as:

- Channel name
- `@handle`
- Channel ID
- YouTube URL

Example:

```text
/yt channel: @PekitaVmo
```

---

## Image Generation

### `/img`

Generate an image using PoLo's image-generation system.

Example:

```text
/img prompt: a white polar bear exploring a snowy mountain
```

The generated image depends on the available image-generation system and its current limitations.

> **Note:** AI-generated content may not always be accurate or identical to the requested prompt.

# 4. PoLo AI

PoLo AI allows your server to interact with PoLo using an AI-powered conversational system.

## Enabling PoLo AI

Server administrators can use:

```text
/ai config
```

From there, the AI can be enabled or disabled and assigned to a specific channel.

### AI channel

You can configure the channel in which PoLo AI is allowed to respond.

This helps prevent AI responses from appearing throughout the entire server.

### PoLo+ AI controls

**PoLo+** is the upcoming premium version of PoLo.

Future PoLo+ features may include additional AI customization, including the ability to configure the role or personality of PoLo through a custom prompt.

> PoLo+ availability and features may change before its official release.

# 8. Troubleshooting

## PoLo is not responding

Check the following:

- Make sure PoLo is online.
- Check that PoLo can view the channel.
- Check that PoLo can send messages.
- Check the permissions required by the command.
- Make sure you are using the correct command.
- Try running the command again.

## A slash command is missing

Discord may need time to update command registration.

Also verify that:

- PoLo is still in the server.
- You have permission to use the command.
- The command is available in your server.
- Discord is displaying the latest command list.

## AI is not responding

If PoLo AI is enabled but not responding:

1. Open `/ai config`.
2. Verify that AI is enabled.
3. Verify the configured channel.
4. Check PoLo's permissions in that channel.
5. Try mentioning PoLo if the configured AI system requires it.
